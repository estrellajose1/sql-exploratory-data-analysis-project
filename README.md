# SQL Exploratory Data Analysis Project (EDA)

A structured, repeatable **SQL-first Exploratory Data Analysis (EDA)** workflow that moves from basic data understanding to advanced analytics patterns like trend analysis, performance tracking, segmentation, and part-to-whole reporting.

This project is designed to be a **portfolio-ready SQL analytics repo** and a reusable template for analyzing any relational dataset.

---

## Why this project exists

EDA is where most analytics value is created:
- You validate data quality
- Learn what the data actually represents
- Identify meaningful dimensions + measures
- Build the foundation for reporting, dashboards, and deeper analysis

This repo provides a **step-by-step SQL EDA framework** that you can apply to any database.

---

## EDA Framework

### Exploratory Data Analysis (EDA)
1. **Database Exploration**  
   Understand schemas, tables, row counts, relationships, missing keys
2. **Dimensions Exploration**  
   Identify categorical fields and how they segment the dataset
3. **Date Exploration**  
   Verify time coverage, granularity, gaps, and seasonality potential
4. **Measures Exploration (Big Numbers)**  
   Validate numeric fields, totals, null rates, outliers
5. **Magnitude**  
   Order-of-magnitude checks and distribution sanity checks
6. **Ranking (Top N / Bottom N)**  
   Find extremes and key drivers quickly

### Advanced Analytics
7. **Change Over Time (Trends)**  
   Growth rates, MoM/WoW, rolling averages
8. **Cumulative Analysis**  
   Running totals, YTD, cohort-style accumulation
9. **Performance Analysis**  
   Actual vs baseline, targets, benchmarks
10. **Part-to-Whole (Proportional)**  
   Mix shift, contribution %, category share
11. **Data Segmentation**  
   Bucketing, cohorts, RFM-style segmentation
12. **Reporting**  
   Final summary tables/views for dashboards & stakeholders
